# Excel Data Analysis Coach

**An AI-powered Excel learning assistant for practical business data analysis.**

**Excel 数据分析教练：** 一个基于真实业务数据的 AI 学习助手，帮助用户学习 Excel 函数、数据透视表、业务数据分析和目标建模。

## Overview｜项目介绍

Excel Data Analysis Coach is an AI Skill designed to help users learn Excel through practical exercises and business scenarios.

Excel Data Analysis Coach 是一个面向 Excel 学习者的 Agent Skill。它通过实际业务场景和互动练习，帮助用户理解 Excel 知识，并提升数据分析能力。

## Features｜主要功能

- **Excel Functions｜Excel 函数：** Learn and practice Excel formulas, conditional calculations, data lookup, and error handling.
- **Pivot Tables｜数据透视表：** Learn data summarization, filtering, sorting, and business reporting.
- **Business Analysis｜业务分析：** Analyze business performance, monthly trends, and key indicators.
- **Target Modeling｜目标建模：** Practice target allocation, completion rate calculations, and performance analysis.
- **Interactive Learning｜互动教学：** Learn step by step through exercises, formula checks, and feedback.

## How to Use｜使用方法

1. Use an Agent platform that supports the Agent Skills format.
2. Install or import this Skill according to the platform's instructions.
3. Provide an Excel file or describe your business data.
4. Ask the assistant to teach a formula, create a pivot table, or analyze business data.
5. Follow the exercises and receive step-by-step guidance.

使用时，可以向 AI 助手提出以下请求：

- 教我使用 Excel 的 IF、SUMIFS 或 XLOOKUP 函数。
- 带我一步一步制作数据透视表。
- 帮我分析每个团队的月度业绩。
- 教我计算目标完成率并建立目标拆解模型。

**Note:** Platform compatibility and file-loading behavior depend on the Agent environment.

## Learning Philosophy｜教学理念

- Learn through real business scenarios.
- Practice step by step instead of simply receiving answers.
- Explain formulas and calculation logic clearly.
- Verify results before drawing conclusions.
- Never invent missing business data or assumptions.

以理解原理、独立操作和掌握分析方法为核心，而不只是直接给出答案。
