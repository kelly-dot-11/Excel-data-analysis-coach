
# Excel 数据透视表实战知识库

## 一、学习目标

通过真实业务数据，掌握Excel数据透视表的制作和分析方法。

学习目标：

1. 理解数据透视表的作用。
2. 掌握行、列、值、筛选器的使用。
3. 学会对原始数据进行分类汇总。
4. 学会按月份、团队、校区、科目分析数据。
5. 学会进行排名和指标计算。
6. 能够独立制作业务数据分析报表。

## 二、数据来源

使用用户提供的Excel工作簿中的明细表。

主要字段：

- 顾问编码
- 顾问姓名
- 所属团队
- 所属校区
- 签约月份
- 科目
- 纳新人次
- 纳新金额

制作数据透视表前，必须检查：

1. 第一行是否为字段标题。
2. 是否存在空白行。
3. 日期字段是否为真正的日期。
4. 金额和人次是否为数值。
5. 是否存在异常或重复数据。

## 三、数据透视表基础知识

### 1. 什么是数据透视表？

数据透视表是Excel中用于快速汇总、分类和分析数据的工具。

可以通过拖动字段，快速完成不同维度的数据统计。

### 2. 四个主要区域

行：决定数据按照什么类别排列。

列：决定数据按照什么维度横向展开。

值：决定需要统计的指标。

筛选器：决定需要筛选哪些数据。

### 3. 创建方法

1. 打开明细表。
2. 点击数据区域中的任意单元格。
3. 选择插入。
4. 点击数据透视表。
5. 确认数据区域。
6. 选择新工作表。
7. 点击确定。
8. 将字段拖入对应区域。

## 四、实战练习

### 练习1：各团队每个月的签约金额

题目要求：

统计各团队每个月的签约金额。

涉及字段：

- 所属团队
- 签约月份
- 纳新金额

推荐字段布局：

行：所属团队

列：签约月份

值：纳新金额（求和）

预期结果：

形成团队与月份交叉的金额汇总表。

检查要点：

1. 金额字段必须使用求和。
2. 日期应按月份展示。
3. 检查是否包含全部团队。
4. 检查各月金额是否正确。

### 练习2：各校区每个月各科目的纳新人次

题目要求：

统计各校区每个月各科目的纳新人次。

涉及字段：

- 所属校区
- 签约月份
- 科目
- 纳新人次

推荐字段布局：

行：所属校区、科目

列：签约月份

值：纳新人次（求和）

预期结果：

可以查看不同校区、不同科目在各月份的纳新人次。

检查要点：

1. 校区是否完整。
2. 科目是否完整。
3. 月份是否正确。
4. 纳新人次是否使用求和。

### 练习3：顾问个人2026年3月至5月总纳新人次排名

题目要求：

计算每位顾问在2026年3月至5月的总纳新人次，并进行排名。

涉及字段：

- 顾问编码
- 顾问姓名
- 签约月份
- 纳新人次

推荐字段布局：

行：顾问编码、顾问姓名

值：纳新人次（求和）

筛选器：

签约月份，筛选2026年3月至5月。

结果处理：

按照纳新人次从大到小排序。

检查要点：

1. 是否筛选正确的三个月份。
2. 是否按顾问个人汇总。
3. 是否按照纳新人次降序排列。
4. 是否存在同名顾问，需要使用顾问编码区分。

### 练习4：计算每个校区2026年5月的人均纳新客单价

题目要求：

仅通过数据透视表处理，计算每个校区2026年5月的人均纳新客单价。

涉及字段：

- 所属校区
- 签约月份
- 纳新人次
- 纳新金额

操作思路：

1. 创建数据透视表。
2. 将所属校区放入行区域。
3. 将签约月份放入筛选区域。
4. 筛选2026年5月。
5. 将纳新金额放入值区域。
6. 将纳新人次放入值区域。
7. 根据题目对客单价的定义，设置相应计算方式。

重要：

必须先确认客单价的计算口径。

如果定义为每人平均纳新金额，则：

人均纳新客单价 = 纳新金额总和 / 纳新人次总和

不得直接将每条明细的金额平均值当作整体客单价。

如果Excel版本支持数据透视表计算字段或数据模型，可以进一步练习在透视分析中计算该指标。

## 五、常见问题

### 1. 为什么金额变成计数？

可能原因：

- 原始金额被存储为文本。
- 数据中存在非数值内容。

解决方法：

检查原始数据格式，修正后刷新数据透视表。

### 2. 为什么月份没有正确分组？

检查签约月份是否为真正的日期格式。

必要时使用数据透视表的组合功能按月分组。

### 3. 为什么修改明细后透视表没有变化？

需要刷新数据透视表。

操作：

右键数据透视表，选择刷新。

如果新增的数据超出了原数据区域，需要重新调整数据源，或使用Excel表格作为动态数据源。

## 六、AI互动教学规范

教学时采用以下流程：

第一步：解释当前题目要解决的业务问题。

第二步：识别题目涉及的字段。

第三步：解释为什么选择这些字段。

第四步：指导用户创建数据透视表。

第五步：指导用户将字段拖入对应区域。

第六步：检查统计方式和筛选条件。

第七步：让用户自己完成一次操作。

第八步：检查最终结果并解释业务含义。
