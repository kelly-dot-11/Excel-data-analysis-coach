
# Excel 函数实战知识库

## 一、学习目标

通过真实业务数据掌握Excel函数的使用方法。

重点培养：
1. 根据业务需求选择合适的函数。
2. 理解函数语法和参数。
3. 独立编写Excel公式。
4. 检查公式计算结果。
5. 将多个函数组合应用于实际业务。

## 三、常用函数知识

### 1. SUM

作用：计算一组数字的总和。

语法：
=SUM(number1,number2,...)

业务场景：
计算所有顾问的纳新金额总和。

### 2. AVERAGE

作用：计算平均值。

业务场景：
计算顾问平均纳新金额。

### 3. IF

作用：根据条件返回不同结果。

语法：
=IF(条件,满足条件时的结果,不满足条件时的结果)

业务场景：
根据月度目标划分目标档位。

### 4. IFS

作用：根据多个条件依次判断并返回结果。

业务场景：
将顾问月度目标划分为高目标、中目标和低目标。

### 5. IFERROR

作用：当公式发生错误时，返回指定内容。

语法：
=IFERROR(公式,错误时返回的内容)

业务场景：
顾问编码查询不到时显示“无归属”。

### 6. SUMIF

作用：满足单个条件时进行求和。

业务场景：
统计某一个团队的纳新金额。

### 7. SUMIFS

作用：满足多个条件时进行求和。

语法：
=SUMIFS(求和区域,条件区域1,条件1,条件区域2,条件2)

业务场景：
统计指定顾问、指定月份的纳新金额。

### 8. COUNTIF

作用：根据一个条件统计数量。

业务场景：
统计某个团队的顾问数量。

### 9. COUNTIFS

作用：根据多个条件统计数量。

业务场景：
统计指定月份、指定校区的业务记录数量。

### 10. XLOOKUP

作用：根据查找值返回对应的数据。

语法：
=XLOOKUP(查找值,查找区域,返回区域,未找到时返回的内容)

业务场景：
根据顾问编码查询所属团队。

### 11. VLOOKUP

作用：根据指定值，在数据区域中查找对应信息。

业务场景：
根据顾问编码查询顾问所属团队。

注意：需要了解查找区域和返回列的关系。

## 四、实际练习题

根据基础Excel实操练习题中的函数题目进行训练。

### Q1：顾问团队查询

根据顾问编码，从明细表查找所属团队。

建议学习：
- XLOOKUP
- VLOOKUP

### Q2：异常值处理

如果明细表中不存在该顾问编码，则显示“无归属”。

建议学习：
- IFERROR
- XLOOKUP的未找到参数

### Q3：目标档位判断

根据月度目标划分：

- 月度目标大于等于180000：高目标
- 月度目标大于等于150000：中目标
- 其他情况：低目标

建议学习：
- IF
- IFS

### Q4：月度业绩分析

计算每个顾问2026年3月：

1. 月度完成金额。
2. 目标完成率。
3. 同期数据。
4. 同比情况。

并进行：
- 目标完成率格式美化。
- 同比增加图标集。

建议学习：
- SUMIFS
- IFERROR
- 除法及百分比格式
- 同期数据匹配
- 条件格式

注意：同比的比较期间必须按照题目实际要求确认，不能随意假设。

## 五、教学规范

每个函数都按照以下步骤讲解：

1. 解释函数作用。
2. 讲解函数语法。
3. 解释每个参数。
4. 给出实际业务案例。
5. 展示完整公式。
6. 解释公式的计算过程。
7. 讲解常见错误。
8. 给出一道类似练习题。

## 六、互动练习要求

AI不能直接把所有答案告诉用户。

应当先提出问题，等待用户尝试。

如果用户回答错误：
- 指出错误位置。
- 解释错误原因。
- 提供思考提示。
- 鼓励重新尝试。

如果用户回答正确：
- 解释公式原理。
- 展示其他可行写法。
- 增加一道进阶练习。

## 七、学习成果

最终要求用户能够独立：

- 使用查找函数。
- 使用条件判断函数。
- 使用多条件求和函数。
- 处理公式异常。
- 计算目标完成率。
- 计算同比和同期数据。
- 组合多个函数解决业务问题。
