
# Excel 函数实战练习题库

## 一、练习规则

本题库用于训练用户独立使用Excel函数解决业务问题。

教学原则：

1. 一次只出一道题。
2. 先让用户理解题目。
3. 不要提前公布答案。
4. 等待用户输入公式。
5. 检查公式逻辑和计算结果。
6. 解释错误原因。
7. 根据掌握情况增加难度。

练习数据优先使用用户上传的Excel工作簿。

如果没有实际数据，不得编造计算结果。

## 二、初级练习：基础函数

### 练习1：计算纳新金额总和

业务问题：

计算明细表中所有记录的纳新金额总和。

学习函数：

SUM

考核目标：

理解求和区域和数值汇总。

### 练习2：计算平均纳新金额

业务问题：

计算所有明细记录的平均纳新金额。

学习函数：

AVERAGE

考核目标：

理解平均值和总金额的区别。

### 练习3：查找最高和最低纳新金额

业务问题：

找出明细中的最高纳新金额和最低纳新金额。

学习函数：

MAX、MIN

考核目标：

掌握最大值和最小值的计算。

## 三、进阶练习：条件判断函数

### 练习4：判断目标完成情况

业务问题：

根据实际完成金额和目标金额，判断是否完成目标。

学习函数：

IF

要求：

- 达到目标：显示“已完成”
- 未达到目标：显示“未完成”

注意：

目标金额需要使用实际题目提供的数据。

### 练习5：划分业绩档位

业务问题：

根据不同的业绩标准，将顾问划分为不同档位。

学习函数：

IF、IFS

要求：

先确认题目中的真实档位标准，再编写公式。

不得擅自将示例阈值当作正式业务标准。

### 练习6：处理查询异常

业务问题：

当顾问编码无法查询到对应团队时，显示“无归属”。

学习函数：

IFERROR、XLOOKUP

考核目标：

掌握查找函数和异常处理的组合。

## 四、中级练习：多条件统计

### 练习7：统计指定团队纳新金额

业务问题：

统计某个团队的纳新金额总和。

学习函数：

SUMIF

### 练习8：统计指定团队指定月份的纳新金额

业务问题：

根据团队和签约月份两个条件，统计纳新金额。

学习函数：

SUMIFS

### 练习9：统计指定校区的业务记录数量

业务问题：

统计某个校区符合条件的业务记录数量。

学习函数：

COUNTIF

### 练习10：多条件统计业务记录

业务问题：

统计指定月份、指定校区的业务记录数量。

学习函数：

COUNTIFS

## 五、高级练习：数据查找

### 练习11：查询顾问所属团队

业务问题：

根据顾问编码查找所属团队。

学习函数：

XLOOKUP、VLOOKUP

### 练习12：组合查找与异常处理

业务问题：

根据顾问编码查找顾问信息。

如果查找失败，显示指定提示。

学习函数：

XLOOKUP、IFERROR

### 练习13：多函数组合

业务问题：

根据顾问编码查询顾问所属校区和团队。

学习函数：

INDEX、MATCH

## 六、综合实战：原始Excel函数题

### Q1：顾问团队查询

根据原始Excel函数题目的要求，使用顾问编码查询所属团队。

考核：

- 是否正确识别查找值。
- 是否选择正确的查找区域。
- 是否返回正确的团队信息。

### Q2：异常处理

当顾问编码不存在时，显示“无归属”。

考核：

- 是否正确处理查找失败。
- 是否理解IFERROR和XLOOKUP的关系。

### Q3：目标档位判断

按照原始题目中的真实标准进行目标档位判断。

考核：

- 是否正确理解业务条件。
- 是否能够使用IF或IFS。
- 是否正确处理临界值。

### Q4：2026年3月月度业绩分析

根据原始题目要求计算：

1. 月度完成金额。
2. 目标完成率。
3. 同期数据。
4. 同比情况。

考核：

- 是否能够使用SUMIFS。
- 是否正确计算目标完成率。
- 是否正确匹配同期数据。
- 是否正确处理除数为零的情况。

注意：

同比比较期间和具体计算口径以原始题目为准。

## 七、AI批改标准

每道练习按照以下维度批改：

| 评分维度 | 分值 |
|---|---:|
| 函数选择正确 | 25 |
| 公式结构正确 | 25 |
| 参数引用正确 | 25 |
| 业务逻辑正确 | 25 |
| 总分 | 100 |

如果用户答案错误：

1. 不要直接给最终答案。
2. 先指出错误位置。
3. 给出思考提示。
4. 让用户重新尝试。
5. 用户需要答案时再完整讲解。

## 八、学习进度管理

每完成一道题，记录：

- 题目编号
- 使用的函数
- 是否正确
- 错误原因
- 掌握程度

根据学习结果推荐下一道练习。

最终目标：

让用户能够独立使用Excel函数解决实际业务问题。
